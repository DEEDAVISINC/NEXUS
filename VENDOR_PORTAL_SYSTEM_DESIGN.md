## 📊 DATABASE SCHEMA

### **Vendors Table:**
```sql
CREATE TABLE vendors (
    id INT PRIMARY KEY AUTO_INCREMENT,
    company_name VARCHAR(255),
    email VARCHAR(255) UNIQUE,
    phone VARCHAR(50),
    website VARCHAR(255),
    address TEXT,
    city VARCHAR(100),
    state VARCHAR(50),
    zip VARCHAR(20),
    service_areas JSON,
    service_categories JSON,
    insurance_gl BOOLEAN,
    insurance_gl_amount DECIMAL(10,2),
    insurance_wc BOOLEAN,
    certifications JSON,
    years_in_business INT,
    experience_types JSON,
    notification_preferences JSON,
    status ENUM('pending', 'approved', 'suspended') DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP
);
```

### **Public RFQs Table:**
```sql
CREATE TABLE public_rfqs (
    id INT PRIMARY KEY AUTO_INCREMENT,
    ddi_rfq_number VARCHAR(50) UNIQUE,
    title VARCHAR(255),
    category VARCHAR(100),
    location_description TEXT,
    contract_value_min DECIMAL(10,2),
    contract_value_max DECIMAL(10,2),
    quote_due_date DATETIME,
    status ENUM('open', 'closed', 'awarded') DEFAULT 'open',
    pdf_url VARCHAR(500),
    short_description TEXT,
    published_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    views INT DEFAULT 0,
    downloads INT DEFAULT 0
);
```

### **Vendor Quotes Table:**
```sql
CREATE TABLE vendor_quotes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    vendor_id INT,
    rfq_id INT,
    quote_amount DECIMAL(10,2),
    quote_notes TEXT,
    attachments JSON,
    submitted_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status ENUM('submitted', 'under_review', 'awarded', 'declined') DEFAULT 'submitted',
    FOREIGN KEY (vendor_id) REFERENCES vendors(id),
    FOREIGN KEY (rfq_id) REFERENCES public_rfqs(id)
);
```
