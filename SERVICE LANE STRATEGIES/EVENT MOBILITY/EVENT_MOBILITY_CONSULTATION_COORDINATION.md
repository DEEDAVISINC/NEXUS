## Positioning

Dee Davis Inc. is **not** a rideshare company. DDI sells **event mobility consultation and coordination** — the program layer venues, cities, and campuses need: PUDO design, wayfinding, pre-event comms, day-of ops, post-event reporting. Fulfillment runs through DDI-managed credentialed mobility network — **one contract, one invoice, one accountable EDWOSB prime.**

**Buyer-facing one-liner:**

> Dee Davis Inc. provides event mobility consultation and coordination — designated pickup/drop-off planning, wayfinding, pre-event communications, and day-of operations oversight — with credentialed fulfillment dispatched nationwide under one EDWOSB contract.

**Do not** name Uber, Lyft, or other fulfillment brands in buyer outreach (`never-name-subvendors-network.mdc`).

## The Split

| DDI (Prime — Consultation & Coordination) | Fulfillment (Network — under DDI contract) |
|---|---|
| Pre-event site assessment & traffic flow | Trip dispatch |
| Geofenced PUDO zone design | Driver assignment |
| Wayfinding & rider comms plan | GPS / mapping |
| Driver briefing templates | Platform notifications |
| Road closure / ingress-egress coordination | Trip execution |
| Pre-event notifications (riders + drivers) | Trip data feed to DDI |
| Day-of command + escalation | — |
| Post-event reporting to the buyer | — |
| **One contract · one invoice · one accountable vendor** | Invisible to the buyer |

Lyft gives consulting away to sell rides. **DDI charges for the program** and coordinates fulfillment behind it.

---

## Consultation Package Deliverables

1. **Discovery** — event type, volume, venue layout, peak windows  
2. **PUDO design** — geofenced zones, walking paths, capacity by gate/entrance  
3. **Comms plan** — rider instructions, driver briefings, pre-event push notifications  
4. **Ops playbook** — road closures, surge windows, escalation tree  
5. **Day-of coordination** — DDI command role, real-time adjustments  
6. **Close-out report** — trip volume, peak times, issues, recommendations for next event
