## EXECUTIVE SUMMARY

DDI already does DOT drug testing. FleetFlow is built for freight/logistics operations. Fleet compliance is the natural bridge — helping trucking companies, fleet operators, and government agencies manage driver qualification files, DOT compliance, and safety programs.

**The Play:** DDI becomes the compliance TPA for fleets — managing driver qualification files, scheduling DOT physicals, coordinating drug testing, tracking MVRs, and ensuring audit-ready compliance. FleetFlow powers the technology. PRISM handles field services (drug tests, physicals).

## FMCSA REQUIREMENTS (What DDI Manages)

### Driver Qualification (DQ) File Requirements
**49 CFR Part 391 — Every CDL driver must have a complete DQ file**

| Document | Requirement | DDI Responsibility |
|---|---|---|
| Driver's Application | Employment history 3 years | Collect, verify, store |
| MVR (Motor Vehicle Record) | Annual review required | Order, review, document |
| Road Test Certificate | OR copy of CDL | Verify, store |
| Medical Examiner's Certificate | Current DOT physical (2 years max) | Schedule, track expiration |
| Annual Driving Record Review | Employer must review MVR annually | Order, flag violations |
| Previous Employer Inquiry | Drug/alcohol history | Request, track, store |
| Drug Testing Records | Pre-employment, random, post-accident | Manage entire program |
| FMCSA Clearinghouse Query | Pre-employment + annual | Run queries, document |
| Driver's License Copy | Valid CDL with endorsements | Verify, track expiration |
| Certificate of Violations | Annual driver certification | Collect, store |

### Order Flow for Drug Testing

```
1. FleetFlow compliance module flags driver for random test
2. PRISM creates drug test order
3. AI matches to nearest collector
4. Collector receives order via PRISM Agent Portal
5. Collector contacts driver, schedules appointment
6. Collection performed
7. Specimen sent to lab
8. Results returned to PRISM
9. Results reported to FleetFlow compliance dashboard
10. If positive: FMCSA Clearinghouse reporting triggered
11. VERTEX invoices fleet operator
```
