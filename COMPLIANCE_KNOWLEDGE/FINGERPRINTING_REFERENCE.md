## REGULATORY FRAMEWORK

### FBI CJIS (Criminal Justice Information Services)
- Sets standards for fingerprint-based criminal background checks
- Manages the NGI (Next Generation Identification) database
- Requires state channeling agencies for civilian access

### State Channeling Agencies
Each state has a designated agency that:
- Receives fingerprints from authorized providers
- Submits to FBI on behalf of civilians
- Returns results to requester

**Common Examples:**
| State | Channeling Agency |
|---|---|
| Michigan | Michigan State Police - CJIS |
| California | DOJ Applicant Services |
| Florida | FDLE |
| Texas | DPS |
| New York | DCJS |

- DDI is SWFT authorized
- Allows direct submission to FBI/state from DDI livescan equipment

## FBI ELECTRONIC SUBMISSION CHANNELS

The FBI has multiple electronic systems for fingerprint submission and background checks:

### 1. FBI Channelers (Approved Private Companies)

**What They Are:**
- FBI-approved private companies authorized to submit fingerprints directly to FBI
- Bypass state channeling agencies for certain use cases
- Faster turnaround than traditional state submission

**Current FBI Approved Channelers:**
| Company | Services |
|---|---|
| **IdentoGO (IDEMIA)** | Livescan, ink card processing, mobile |
| **Fieldprint** | Livescan for education, healthcare, gaming |
| **MorphoTrust** | Government, healthcare, transportation |
| **Accurate Biometrics** | Livescan, card scan |
| **Certifix** | Livescan network |

**DDI Opportunity:** Partner with channelers or pursue channeler authorization

### 2. NGI (Next Generation Identification)

**FBI's Core Biometric Database:**
- Replaced IAFIS in 2014
- Contains 150M+ fingerprint records
- Advanced matching algorithms
- Supports tenprint, latent prints, palm prints

**Submission Types:**
| Type | Code | Purpose |
|---|---|---|
| Criminal Ten-print | CAR | Arrest/booking |
| Civil Applicant | CAP | Employment/licensing |
| Latent Print | LAT | Crime scene investigation |
| NIST Special | NST | Federal employment |

### 3. Rap Back (Retention & Ongoing Monitoring)

**What It Is:**
- Proactive notification service
- Employer enrolled → FBI notifies of subsequent arrests
- Continuous monitoring after initial background check

**How It Works:**
1. Initial fingerprint background check conducted
2. Employer enrolls in Rap Back for that individual
3. FBI retains fingerprints
4. If individual is subsequently arrested, employer is notified

**Use Cases:**
- Schools (teachers, staff)
- Healthcare (patient access)
- Financial services
- Government contractors
- Childcare facilities

**State Rap Back Programs:**
Many states have their own Rap Back equivalent for state-level arrests

### 4. NICS (National Instant Criminal Background Check System)

**For Firearms Only:**
- NOT fingerprint-based (uses name/DOB)
- Instant check at point of sale
- Different from FBI fingerprint background checks
- DDI does NOT provide NICS (gun dealers only)

### 5. Identity History Summary (Personal Background Check)

**Individual Requests Own Record:**
- Anyone can request their own FBI Identity History Summary
- Submission: Ink card or electronic via approved channeler
- Cost: ~$18 (as of 2024)
- Use: Personal records, immigration, foreign visa

**How to Request:**
1. Go to fbi.gov/services/cjis/identity-history-summary-checks
2. Electronic submission via approved channeler OR
3. Mail ink card (FD-258) to FBI

### 6. DCII (Defense Counterintelligence and Security Agency)

**For Security Clearances:**
- e-QIP (Electronic Questionnaires for Investigations Processing)
- Federal background investigations
- Fingerprints submitted as part of clearance process

## FINGERPRINT TYPES

### Livescan (Electronic)
- **Digital capture** — No ink, no cards
- **Instant submission** — Transmitted electronically
- **Higher quality** — Automated quality checks
- **Faster results** — Hours to days, not weeks
- **Preferred method** — Most agencies require livescan

### Ink-and-Roll (Paper Cards)
- **FD-258 form** — Standard FBI fingerprint card
- **Manual process** — Ink applied to fingers, rolled onto card
- **Mail submission** — Physical card mailed to agency
- **Slower results** — Weeks to months
- **Still required** — Some agencies, immigration, name checks

### Mobile Livescan
- **Portable equipment** — For on-site collections
- **Same standards** — Same quality requirements as stationary
- **Connectivity required** — Need secure network for submission

## COLLECTION PROCEDURES

### Livescan Collection — Step by Step

| Step | Action | Quality Check |
|---|---|---|
| 1 | **Verify identity** — Government-issued photo ID required | Record ID type, number |
| 2 | **Confirm reason for prints** — Know the ORI and purpose | Correct ORI is critical |
| 3 | **Enter applicant data** — Name, DOB, SSN (last 4), address | Verify spelling |
| 4 | **Prepare hands** — Clean, dry, free of lotion | Moisture = poor capture |
| 5 | **Position hand on platen** — Flat, centered | Check alignment |
| 6 | **Capture 4-finger slaps** — Both hands | NFIQ score 3+ required |
| 7 | **Capture individual rolls** — All 10 fingers | Watch for slippage |
| 8 | **Capture thumbs** — Both thumbs flat | Ensure full capture |
| 9 | **Quality review** — All prints meet standards | Reject poor quality |
| 10 | **Retake if needed** — Up to 3 attempts per finger | Document retakes |
| 11 | **Transmit** — Secure submission to agency | Confirm receipt |
| 12 | **Provide receipt** — Give applicant transaction number | For tracking |

### FD-258 Ink Card Collection

| Step | Action | Critical Points |
|---|---|---|
| 1 | **Verify identity** — Government-issued photo ID | Record on card |
| 2 | **Complete header** — All required fields on FD-258 | Use BLOCK letters |
| 3 | **Prepare ink pad** — Even ink distribution | Not too much, not too little |
| 4 | **Roll each finger** — Nail to nail, in sequence | Smooth rolling motion |
| 5 | **Take flat impressions** — Simultaneous impressions | For verification |
| 6 | **Review quality** — Clear ridges, no smudges | Redo if needed |
| 7 | **Sign and date** — Collector signature required | Applicant does NOT sign |
| 8 | **Mail to agency** — Per their instructions | Use proper packaging |

## ORI (Originating Agency Identifier)

### What is an ORI?
- 9-character code identifying the requesting agency
- Determines where results are sent
- **CRITICAL:** Wrong ORI = results go to wrong place

### How to Get the Right ORI
1. **Client provides** — They know their licensing board's ORI
2. **State agency list** — States publish ORI lists for common purposes
3. **Call the licensing board** — If unsure, verify with the agency

### Common ORI Categories
| Purpose | Who Provides ORI |
|---|---|
| Nursing license | State Board of Nursing |
| Teacher certification | State Dept of Education |
| Real estate license | State Real Estate Commission |
| Concealed carry permit | Local sheriff/police |
| Employment (federal) | Employer/HR |
| Adoption | Adoption agency |

## QUALITY STANDARDS

### NFIQ (NIST Fingerprint Image Quality)
- Scale: 1-5 (1 = best, 5 = worst)
- **Minimum accepted:** NFIQ 3 or better
- **Target:** NFIQ 1-2 for clean submissions

### Common Quality Issues

| Issue | Cause | Solution |
|---|---|---|
| **Low contrast** | Dry fingers | Apply light moisture |
| **Smudged** | Movement during capture | Steady hand, slower roll |
| **Incomplete** | Finger not fully on platen | Reposition, retry |
| **Excessive pressure** | Pressing too hard | Lighter touch |
| **White lines** | Cuts, scars, peeling skin | Document, submit "best effort" |
| **No ridges** | Worn fingerprints (age, manual labor) | Document, submit "best effort" |

### Handling Difficult Prints

**Worn/faint ridges (common in elderly, manual laborers):**
1. Apply thin layer of hand lotion, wait 2 minutes, wipe off
2. Light moisture (breath on fingers)
3. Multiple attempts at different pressures
4. Document "best effort" in notes
5. May require ink card backup

**Cuts/bandages:**
- Capture what you can
- Document injury
- May need to return after healing

**Missing fingers:**
- Mark "XX" or "AMP" in that position
- Document reason
- Some agencies have specific codes

## COMMON ERRORS — WHAT CAUSES REJECTION

### Submission Rejected

| Error | Cause | Prevention |
|---|---|---|
| **Wrong ORI** | Results sent to wrong agency | Verify ORI before submission |
| **Name mismatch** | Name doesn't match other records | Verify exact legal name from ID |
| **Low quality** | Prints don't meet NFIQ standards | Retake until quality achieved |
| **Incomplete set** | Missing fingers without documentation | Document missing fingers |
| **Invalid ID** | Expired or unacceptable ID type | Require current government ID |
| **System error** | Transmission failure | Resubmit when system available |

### Quality Rejection from FBI/State

If prints rejected for quality:
1. Contact applicant for recollection
2. Try different technique (pressure, moisture)
3. If still failing, may need ink card backup
4. Document extensive efforts for "best effort" submission
