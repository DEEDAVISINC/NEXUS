## OVERVIEW

Occupational health services include medical examinations and testing required by:
- **DOT (Department of Transportation)** — CDL driver physicals

DDI provides occupational health services through the PRISM network of certified medical examiners.

## DOT PHYSICAL EXAMINATIONS

### What is a DOT Physical?
- Medical examination required for commercial drivers (CDL holders)
- Determines if driver is medically qualified to operate commercial motor vehicles
- Performed by FMCSA-certified Medical Examiner (ME)
- Results in Medical Examiner's Certificate (MEC) or disqualification

### Regulatory Authority
- **49 CFR Part 391** — Qualification of drivers
- **FMCSA (Federal Motor Carrier Safety Administration)** — Oversight
- **National Registry of Certified Medical Examiners** — ME certification

### Who Needs a DOT Physical?

| Driver Type | DOT Physical Required |
|---|---|
| CDL Class A, B, C (interstate) | YES |
| CDL Class A, B, C (intrastate) | YES (most states) |
| Non-CDL CMV (over 10,001 lbs) | YES (interstate) |
| Hazmat haulers | YES |
| Passenger vehicles (16+ passengers) | YES |
| Regular passenger vehicle (personal) | NO |

### Medical Examiner Requirements
- Must be listed on FMCSA National Registry
- Must complete FMCSA training program
- Must pass FMCSA certification exam
- Must recertify every 10 years (5 years continuing education)

## DOT PHYSICAL — EXAMINATION COMPONENTS

### Required Testing

| Component | What's Checked | Standards |
|---|---|---|
| **Vision** | Acuity, color vision, peripheral | 20/40 each eye, 70° field |
| **Hearing** | Whispered voice or audiometry | Perceive whisper at 5 feet |
| **Blood pressure** | Hypertension screening | <140/90 for 2-year cert |
| **Urinalysis** | Protein, blood, sugar | Diabetes/kidney screen |
| **Physical exam** | General health assessment | Per 49 CFR 391.41 |

### Vision Standards

| Requirement | Standard |
|---|---|
| Distant acuity | 20/40 or better in each eye (with or without correction) |
| Distant acuity (both eyes) | 20/40 or better |
| Field of vision | 70 degrees horizontal in each eye |
| Color vision | Distinguish traffic signal colors |

**If corrective lenses required:** Restriction noted on MEC, driver must wear while driving.

### Hearing Standards

| Test Method | Standard |
|---|---|
| Whispered voice | Perceive whisper at 5 feet or more (best ear) |
| Audiometric | Average ≤40 dB at 500, 1000, 2000 Hz (best ear) |

**Hearing aids permitted:** If hearing aid required, must be worn while driving.

### Blood Pressure Guidelines

| BP Reading | Certification Period |
|---|---|
| <140/90 | 2-year maximum |
| 140-159 / 90-99 (Stage 1) | 1-year maximum |
| 160-179 / 100-109 (Stage 2) | 1-time 1-year certification, then must be <140/90 |
| ≥180 / ≥110 (Stage 3) | DISQUALIFIED until controlled |

### Disqualifying Conditions

**Absolute Disqualifiers (cannot certify):**
- Loss of hand, arm, foot, leg (unless SPE certificate)
- Insulin-treated diabetes (unless exemption)
- Epilepsy/seizure disorder (unless exemption)
- Mental, nervous, organic, or functional condition likely to interfere
- Current use of Schedule I drugs
- Positive DOT drug test (until SAP process complete)

**Temporary Disqualifiers:**
- Recent heart attack (must wait)
- Recent stroke (must wait)
- Unstable conditions being treated
- Medication side effects that impair

## OSHA MEDICAL SURVEILLANCE

### What is Medical Surveillance?
- Ongoing monitoring of workers exposed to occupational hazards
- Required by various OSHA standards
- Typically includes baseline, periodic, and exit exams

### Common OSHA Medical Surveillance Requirements

| OSHA Standard | Hazard | Testing Required |
|---|---|---|
| **29 CFR 1910.134** | Respirator use | Respirator medical evaluation, fit testing |
| **29 CFR 1910.95** | Noise exposure | Audiometric testing |
| **29 CFR 1910.1025** | Lead exposure | Blood lead level, ZPP |
| **29 CFR 1910.1027** | Cadmium | Blood/urine cadmium, medical exam |
| **29 CFR 1910.1028** | Benzene | Blood count, physical exam |
| **29 CFR 1910.1030** | Bloodborne pathogens | Hepatitis B vaccination, post-exposure |
| **29 CFR 1910.1048** | Formaldehyde | Medical history, physical exam |
| **29 CFR 1910.1001** | Asbestos | Chest X-ray, pulmonary function |
| **29 CFR 1910.1096** | Ionizing radiation | As specified by employer program |

## RESPIRATOR MEDICAL EVALUATION

### When Required
- Before an employee is fit tested for a respirator
- Before an employee uses a respirator on the job
- Required by 29 CFR 1910.134(e)

### Evaluation Process

1. **Questionnaire** — Worker completes OSHA respirator medical evaluation questionnaire
2. **Review** — PLHCP (Physician or Licensed Health Care Professional) reviews
3. **Follow-up** — Additional testing if questionnaire indicates concerns
4. **Determination** — PLHCP issues written opinion on ability to use respirator

### Medical Determination Outcomes

| Determination | Meaning |
|---|---|
| **Cleared** | Can use respirator |
| **Cleared with restrictions** | Can use certain types only |
| **Not cleared** | Cannot use respirator |
| **Requires additional evaluation** | Need more testing |

### Follow-up Examinations Triggered By

- Questionnaire responses indicating potential problems
- Signs/symptoms related to respirator use
- Employee request
- Observations by PLHCP, employer, or program administrator

## RESPIRATOR FIT TESTING

### When Required
- Before first use of a tight-fitting respirator
- Annually thereafter
- When respirator type/size changes
- When physical changes may affect fit (weight change, dental work, facial scarring)

### Fit Test Methods

**Qualitative (QLFT) — Pass/Fail:**
- Saccharin (sweet taste)
- Bitrex (bitter taste)
- Irritant smoke (cough)
- Isoamyl acetate (banana smell)

**Quantitative (QNFT) — Measured:**
- Ambient aerosol CNC
- Controlled negative pressure (CNP)
- Generated aerosol

### Fit Test Protocol (OSHA Appendix A)

1. Select appropriate respirator size
2. Don respirator, perform user seal check
3. Perform fit test exercises (each 1 minute):
   - Normal breathing
   - Deep breathing
   - Head side to side
   - Head up and down
   - Talking (reading Rainbow Passage)
   - Grimace (QNFT only)
   - Bending over
   - Normal breathing
4. Record results
5. Issue fit test documentation

### Fit Test Records

| Element | Required |
|---|---|
| Employee name | YES |
| Type of fit test | YES |
| Respirator make/model/size | YES |
| Date of test | YES |
| Pass/fail (or fit factor) | YES |
| Test administrator | YES |

## AUDIOMETRIC TESTING

### When Required (29 CFR 1910.95)
- Workers exposed to 85 dB TWA (time-weighted average) or above
- Baseline within 6 months of first exposure
- Annual audiogram thereafter

### Testing Protocol

| Element | Requirement |
|---|---|
| **Baseline** | Within 6 months of first exposure (14 hours quiet before test) |
| **Annual** | Within 12 months of previous test |
| **Equipment** | Calibrated audiometer |
| **Frequencies** | 500, 1000, 2000, 3000, 4000, 6000 Hz |
| **Environment** | Background noise below specified levels |
| **Technician** | Trained audiometric technician or audiologist |

### Standard Threshold Shift (STS)

**Definition:** Average shift of 10 dB or more at 2000, 3000, 4000 Hz in either ear

**If STS occurs:**
1. Notify employee within 21 days
2. Fit or refit hearing protection
3. Refer for audiological evaluation if needed
4. Consider additional engineering controls

### Audiometric Testing Records

| Element | Required |
|---|---|
| Employee name | YES |
| Date of test | YES |
| Examiner name | YES |
| Audiogram results | YES |
| Background noise levels | YES |
| Audiometer calibration date | YES |

## PRE-EMPLOYMENT PHYSICALS

### Employer-Mandated (Not DOT)
- Determined by employer policy
- Must comply with ADA (Americans with Disabilities Act)
- Cannot ask disability-related questions before conditional job offer
- Must be job-related and consistent with business necessity

### ADA Compliance

**Before conditional job offer:**
- ❌ Cannot require medical exam
- ❌ Cannot ask about disabilities
- ✅ Can ask about ability to perform job functions

**After conditional job offer:**
- ✅ Can require medical exam
- ✅ Exam must be same for all entering employees in job category
- ✅ Cannot withdraw offer unless condition prevents essential functions AND no reasonable accommodation

### Common Pre-Employment Physical Components

| Component | Purpose |
|---|---|
| Medical history | Baseline health information |
| Physical examination | General health assessment |
| Drug screen | Employer drug-free workplace |
| Vision test | Job-related visual requirements |
| Lifting assessment | Physical capability for job |
| Pulmonary function | For respirator users |

## RETURN TO WORK / FITNESS FOR DUTY

### When Used
- After injury or illness
- After extended absence
- When behavior suggests impairment
- Per employer policy

### Evaluation Scope
- Determined by employer policy and reason for exam
- Must be job-related
- Focus on ability to perform essential functions
- Identify any restrictions or accommodations needed

### Documentation

| Element | Included |
|---|---|
| Cleared to return | YES/NO |
| Restrictions | If any |
| Duration of restrictions | Temporary or permanent |
| Follow-up needed | Date of next evaluation |
| Accommodations recommended | If any |

## COMMON TESTING — QUICK REFERENCE

### Drug Testing (Cross-Reference: 49 CFR Part 40)
- See `49_CFR_PART_40_REFERENCE.md` for complete DOT drug testing
- Non-DOT drug testing follows employer policy
- Same collection process, different authority

### TB Testing
- Mantoux skin test (TST) or IGRA blood test
- Required for healthcare workers
- Required for some food handlers
- Positive result requires chest X-ray

### Hepatitis B
- Vaccination offered to workers with occupational exposure to blood
- Titer test to confirm immunity
- Post-exposure testing and prophylaxis

### Blood Lead Level
- Required for workers exposed to lead
- Frequency based on exposure level
- Action levels trigger removal from exposure

- [ ] Documentation maintained

- [ ] Verify medical clearance for respirator

- [ ] Document results

- [ ] Verify 14-hour quiet period (baseline only)

- [ ] Compare to baseline
- [ ] Calculate if STS occurred
