# FATAL FLAW CHECKLIST — DOT DRUG & ALCOHOL TESTING

**Fatal flaw = Test MUST be cancelled. No exceptions. No corrections.**

**Use this checklist for PRISM scanback inspection and collection quality control.**

---

## DRUG TEST FATAL FLAWS (49 CFR §40.199)

### CCF Form Errors — FATAL

| # | Fatal Flaw | Check | If Found |
|---|---|---|---|
| 1 | **No collector signature on CCF** | ☐ | CANCEL TEST |
| 2 | **No donor signature on CCF** (and not corrected per §40.73) | ☐ | CANCEL TEST |
| 3 | **Specimen ID number on bottle doesn't match CCF** | ☐ | CANCEL TEST |
| 4 | **Specimen bottle seal broken or shows evidence of tampering** | ☐ | CANCEL TEST |
| 5 | **Insufficient specimen volume for testing** | ☐ | CANCEL TEST |
| 6 | **No printed collector name AND collector cannot be identified** | ☐ | CANCEL TEST |

### Chain of Custody Breaks — FATAL

| # | Fatal Flaw | Check | If Found |
|---|---|---|---|
| 7 | **Seal not intact when received at lab** | ☐ | CANCEL TEST |
| 8 | **Specimen container leaking with specimen lost** | ☐ | CANCEL TEST |
| 9 | **Specimen ID completely illegible on bottle AND CCF** | ☐ | CANCEL TEST |

## DRUG TEST CORRECTABLE FLAWS (MRO Can Fix)

These are NOT fatal — MRO can correct through documentation:

| Flaw | Correction |
|---|---|
| Missing donor signature (not fatal per §40.73) | MRO documents attempt to obtain |
| Missing collector phone number | MRO obtains from collection site |
| Missing employer information | MRO obtains from C/TPA |
| Transposed numbers (specimen ID) | MRO verifies with lab/collector |
| Missing date | MRO obtains from collector |

## PRISM SCANBACK INSPECTION — FATAL FLAW DETECTION

### For Every Drug Test Scanback

**STEP 1: Visual Inspection**
```
☐ Is the CCF image clear and legible?
☐ Are all 5 copies visible/accounted for?
☐ Is the specimen bottle seal intact (no tears, no tampering)?
```

**STEP 2: Signature Check**
```
☐ Collector signature present? → If NO = FATAL
☐ Collector name printed? → If NO and unidentifiable = FATAL
☐ Donor signature present? → If NO, check §40.73 documentation
```

**STEP 3: Specimen ID Match**
```
☐ Specimen ID on bottle visible?
☐ Specimen ID on CCF visible?
☐ Do they match exactly? → If NO = FATAL
```

**STEP 4: Seal Integrity**
```
☐ Primary bottle seal intact?
☐ Split specimen bottle seal intact?
☐ No evidence of tampering? → If tampering = FATAL
```

**STEP 5: Temperature Check**
```
☐ Temperature recorded on CCF?
☐ Temperature within 90°-100°F?
☐ If out of range, was observed collection documented?
```

### Scanback Result

| All Checks Pass | Result |
|---|---|
| ☑ YES | APPROVED — Release to MRO |
| ☐ NO — Correctable | FLAG — MRO corrects |
| ☐ NO — Fatal Flaw | REJECTED — Cancel test, retest |

## WHAT HAPPENS AFTER CANCELLED TEST

### Pre-Employment Test
- **Employer MUST retest** before employee can work
- Cancelled test does NOT satisfy testing requirement

### Random Test
- **Employer SHOULD retest** immediately
- Employee selection was valid, test was not

### Post-Accident Test
- **If within timeframe** — Retest immediately
- **If outside timeframe** — Document why, no test (follow missed test procedures)

### Return-to-Duty Test
- **Employer MUST retest** — Cannot return without valid negative

### Follow-Up Test
- **Employer MUST retest** — Follow-up plan continues

## COMMON COLLECTOR MISTAKES THAT CAUSE FATAL FLAWS

### Mistake 1: Forgetting to Sign
**Prevention:** Sign CCF immediately after sealing specimen

### Mistake 2: Specimen ID Mismatch
**Prevention:** 
- Read specimen ID aloud while applying to bottle
- Verify donor sees ID match
- Double-check before sealing shipping bag

### Mistake 3: Seal Applied Incorrectly
**Prevention:**
- Apply seal across cap/bottle seam
- Press firmly
- Have donor initial immediately
- Inspect seal before packaging

### Mistake 4: Insufficient Volume Shipped
**Prevention:**
- Verify 45mL minimum BEFORE splitting
- 30mL in primary bottle
- 15mL in split bottle
- If insufficient — shy bladder protocol, not partial collection

### Mistake 5: Temperature Not Checked
**Prevention:**
- Check temperature WITHIN 4 MINUTES of collection
- Record actual temperature (not just "in range")
- If out of range — immediate observed collection

**Before Collection:**
```
☐ Collection supplies complete and sealed?
```

```
☐ Specimen ID matches CCF?
```

**Before Shipping:**
```
☐ Final seal integrity check?
☐ Copy 1 in shipping bag with specimen?
☐ Chain of custody documented?
☐ Shipped same day?
```
