## REGULATORY FRAMEWORK

### State-by-State Regulation
- **Every state** regulates notaries differently
- **Commission** issued by Secretary of State (or equivalent)
- **Jurisdiction** limited to commissioning state
- **Some documents** require specific state notary (real estate)

### Key Regulatory Bodies

| State | Commissioning Authority |
|---|---|
| Michigan | Secretary of State |
| California | Secretary of State |
| Florida | Governor's Office |
| Texas | Secretary of State |
| New York | Secretary of State (county level) |

### Federal Notarization
- No federal notary commission for civilians
- Military JAG officers can notarize for military
- Consular officers notarize abroad
- Some federal agencies accept any state notary

## TYPES OF NOTARIAL ACTS

### 1. Acknowledgment
**Purpose:** Signer acknowledges they signed the document voluntarily

**Requirements:**
- Signer personally appears before notary
- Notary verifies signer's identity
- Signer acknowledges (not necessarily signs in notary's presence)
- Notary completes acknowledgment certificate

**Common Uses:**
- Deeds and real estate transfers
- Powers of attorney
- Trusts
- Corporate documents

**Certificate Language (varies by state):**
```
State of Michigan
County of Oakland

On [date], before me personally appeared [name], 
known to me (or proved to me on the basis of satisfactory evidence) 
to be the person whose name is subscribed to the within instrument 
and acknowledged to me that he/she executed the same in his/her 
authorized capacity, and that by his/her signature on the instrument 
the person, or the entity upon behalf of which the person acted, 
executed the instrument.

WITNESS my hand and official seal.

_________________________
Notary Public
My Commission Expires: [date]
```

### 2. Jurat (Oath/Affirmation)
**Purpose:** Signer swears or affirms the contents of the document are true

**Requirements:**
- Signer MUST sign in notary's presence
- Notary administers oath or affirmation
- Signer swears/affirms under penalty of perjury
- Notary completes jurat certificate

**Common Uses:**
- Affidavits
- Sworn statements
- Depositions
- Financial statements

**Certificate Language:**
```
State of Michigan
County of Oakland

Subscribed and sworn to (or affirmed) before me 
on [date] by [name].

_________________________
Notary Public
My Commission Expires: [date]
```

### 3. Copy Certification
**Purpose:** Certify that a copy is a true copy of an original document

**Requirements:**
- Notary compares copy to original
- Original is not a public record (birth certificate, etc.)
- Notary certifies copy is accurate reproduction

**NOT allowed for:**
- Vital records (birth, death, marriage certificates)
- Public records
- Documents where certified copies must come from issuing agency

**Common Uses:**
- Diplomas
- Passports (for informational purposes, not official)
- Personal documents
- Business records

### 4. Signature Witnessing
**Purpose:** Notary witnesses signer signing the document

**Requirements:**
- Signer signs in notary's presence
- No oath required (unlike jurat)
- Notary notes they witnessed the signature

**Common Uses:**
- Wills (in some states)
- Contracts requiring witnessed signatures
- Medical directives

## IDENTITY VERIFICATION

### Acceptable Identification

**Primary IDs (generally accepted in all states):**
- State driver's license (current)
- State ID card (current)
- US Passport (current)
- US Military ID

**Secondary IDs (may require additional verification):**
- Foreign passport with US visa
- Permanent resident card (green card)
- Student ID (usually not sufficient alone)
- Employee ID (usually not sufficient alone)

### Identification Requirements

| Requirement | Standard |
|---|---|
| Photo | Must be present and recognizable |
| Expiration | Must be current (not expired) |
| Physical description | Should match signer |
| Signature | If present, should match |

### Credible Witnesses
When signer lacks acceptable ID:
- One or two credible witnesses (varies by state)
- Witnesses must have acceptable ID
- Witnesses must personally know the signer
- Witnesses must personally know the notary (some states)
- Witnesses swear to signer's identity

## JOURNAL REQUIREMENTS

### Mandatory Journal States
Some states require notaries to keep a journal of all notarial acts:
- California (mandatory)
- Colorado (mandatory)
- Arizona (mandatory)
- Missouri (mandatory)
- Texas (mandatory for acknowledgments)

### Journal Entry Contents

| Element | Required |
|---|---|
| Date and time | YES |
| Type of notarial act | YES |
| Document type | YES |
| Signer name | YES |
| Signer address | Varies |
| ID type and number | Recommended |
| Signature of signer | Varies |
| Fee charged | Varies |
| Notes | Optional |

### Best Practice
**Keep a journal even in non-mandatory states:**
- Protects notary in disputes
- Provides evidence of proper procedure
- Professional standard

## REMOTE ONLINE NOTARIZATION (RON)

### What is RON?
- Notarization via live audio-video communication
- Signer and notary in different physical locations
- Electronic document, electronic signature, electronic seal
- Session recorded for compliance

### States Allowing RON (as of 2026)
**Most states now allow RON, including:**
- Michigan (YES - since 2018)
- Texas (YES)
- Florida (YES)
- Virginia (YES - pioneer state)
- Ohio (YES)
- Nevada (YES)

**Check current state authorization before offering RON.**

### RON Requirements

| Requirement | Details |
|---|---|
| **Platform** | Must use authorized RON platform |
| **Identity proofing** | Knowledge-based authentication (KBA) |
| **Credential analysis** | Automated ID verification |
| **Audio-video** | Live, synchronous session |
| **Recording** | Full session recorded and retained |
| **Electronic seal** | Tamper-evident e-seal applied |
| **Session log** | Detailed log of session actions |

### RON Process

1. **Schedule session** — Signer books through RON platform
2. **Identity proofing** — KBA questions (5 questions, 4 must be correct)
3. **Credential analysis** — ID scanned and verified
4. **Connect live** — Audio-video session begins
5. **Verify identity** — Notary confirms signer matches ID
6. **Review document** — Notary can see document on screen
7. **Administer oath** (if jurat) — Verbal oath/affirmation
8. **Signer signs** — Electronic signature applied
9. **Notary signs/seals** — Electronic notarial certificate completed
10. **Session ends** — Recording saved per retention requirements

### RON Limitations

- **Real estate:** Some states/counties don't accept RON for property transfers
- **Wet signatures:** Some documents specifically require original ink signature
- **Signer comfort:** Not all signers comfortable with technology
- **International:** RON laws vary; may not be accepted abroad

## MOBILE NOTARY SERVICES

## LOAN SIGNING AGENT (LSA)

### Special Training Required
Loan signings require additional training beyond basic notary commission:
- Understanding of mortgage documents
- Signing Agent certification (NNA, LSS)
- E&O insurance (required by most title companies)
- Background check (for title company approval)

### Loan Signing Process

1. **Assignment** — Title company assigns closing
2. **Document delivery** — Receive loan package (usually electronic)
3. **Print documents** — If paper signing
4. **Travel to signing** — Meet borrower at agreed location
5. **Verify identity** — Standard notarial ID verification
6. **Guide through documents** — Present each document, explain (not legal advice)
7. **Notarize where required** — Not all documents notarized
8. **Return documents** — Ship/upload completed package
9. **Confirm completion** — Notify title company

### What LSAs Cannot Do
- ❌ Explain terms of the loan (that's legal advice)
- ❌ Answer questions about rates, payments, terms
- ❌ Advise borrower to sign or not sign
- ❌ Make changes to documents

### What LSAs Should Do
- ✅ Present each document
- ✅ Point out signature/initial lines
- ✅ Read document titles aloud
- ✅ Direct questions to lender/title company
- ✅ Remain neutral and professional

## COMMON ERRORS — WHAT VOIDS A NOTARIZATION

### Fatal Errors

| Error | Why It's Fatal |
|---|---|
| **Notarizing without signer present** | Fundamental violation |
| **Not verifying identity** | Cannot confirm who signed |
| **Incomplete certificate** | Missing required elements |
| **Notarizing own signature** | Conflict of interest |
| **Notarizing for family member** | Conflict of interest (most states) |
| **Expired commission** | No authority to notarize |
| **Outside jurisdiction** | No authority in that state |
| **Backdating** | Falsifying the record |

### Correctable Issues

| Issue | Correction |
|---|---|
| Wrong date on certificate | Re-notarize (do not alter) |
| Incomplete certificate | Complete if signer available |
| Missing seal | Affix seal if document available |
| Wrong county | Re-notarize with correct venue |

## APOSTILLE & AUTHENTICATION

### What is an Apostille?
- International certification of notarized document
- Used in countries that are members of Hague Convention
- Issued by Secretary of State (or equivalent)

### Process

1. Document notarized
2. Submit to Secretary of State for apostille
3. Apostille certificate attached
4. Document accepted in Hague member countries

### Authentication (Non-Hague Countries)
For countries not in Hague Convention:
1. Document notarized
2. Secretary of State certifies notary's signature
3. US State Department authenticates
4. Embassy/consulate of destination country legalizes
