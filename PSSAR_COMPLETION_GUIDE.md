## PART 2 — APPLICATIONS

### Section 14: DCII (Defense Central Index of Investigations)
**SKIP THIS ENTIRE SECTION** — Government only, does not apply to industry/contractor applicants.

### Section 15: SWFT (Secure Web Fingerprint Transmission) ← THIS IS THE KEY SECTION

| # | Field | What to Check |
|---|-------|---------------|
| **15.a** | Permissions — Fingerprint Submission | |
| | ☑ **ENROLLER** | *Yes — this lets you capture and submit fingerprints through SWFT* |
| | ☐ ENROLLER SITE ADMINISTRATOR | *Only if you want to manage other enrollers at your site — check this too if you're the only person doing it* |
| | ☑ **TRANSACTION VIEWER** | *Yes — this lets you view the status of fingerprint submissions* |
| **15.b** | Permissions — Fingerprint Enrollment | **SKIP** — Government only |
| **15.c** | Additional CAGE Codes | **Leave blank** *(you're using 8UMX3 as the primary in field 12)* |

**Recommended:** Check both **ENROLLER** and **TRANSACTION VIEWER**. If you want to manage the account and add future employees, also check **ENROLLER SITE ADMINISTRATOR**.

### Section 16: JCAVS (Joint Clearance Access Verification System)
**SKIP THIS ENTIRE SECTION** — You're requesting SWFT access only, not JCAVS.

### Section 17: JAMS (Joint Adjudication Management System)
**SKIP THIS ENTIRE SECTION** — CAF (Central Adjudication Facility) only.
