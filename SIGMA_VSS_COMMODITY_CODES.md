## HOW TO USE THIS ON OTHER PORTALS

When registering on a new vendor portal, search for the **description keywords** — not the Michigan code numbers. Each state uses its own code system (NIGP, UNSPSC, or custom).

| Portal | Code System | How to Search |
|---|---|---|
| Michigan SIGMA VSS | Michigan NIGP hybrid | Use codes above directly |
| Kentucky VSS | NIGP | Search by description keyword |
| Maryland eMMA | NIGP | Search by description keyword |
| BidNet / MITN | NIGP | Search by description keyword |
| Ohio | NIGP | Search by description keyword |
| Georgia GPR | NIGP / custom | Search by description keyword |
| SAM.gov | NAICS (not NIGP) | Use DDI's NAICS codes instead |

**Rule:** Always search by description first, then verify the code matches the service. Log the verified code here.

## NOTES

- **9S3 vs 9S301:** Sarah Oumedian (MDHHS) referenced "9S3" informally — the full code in SIGMA is **9S301**. Always use the full code when searching.
- **19348 (Drug Testing Kits):** Covers the product/supply side of drug testing — cups, cards, strips. Different from 95207 which covers the testing service. Both needed for Hall County-type bids.
- **SIGMA VSS notification:** With these codes in the vendor profile, SIGMA will automatically email DDI when a matching solicitation is published. No manual checking needed.
