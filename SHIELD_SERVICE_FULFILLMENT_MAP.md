## How SHIELD Connects It All

Every service line above flows through SHIELD with **automated verification and status-driven payment**:

```
Referral → Navigator → Service Activated → Vendor Dispatched → TWO-WAY VERIFICATION → Payment Released
  /refer     SHIELD       Supervisor OK       Auto-SMS            Contractor ✓            VERTEX
                                                                  + Family ✓              Billing
                                                                  = Verified Complete
```

### Verification Chain (No Manual Trust Required)
1. **Service Activated** — Navigator requests, supervisor approves
2. **Vendor Dispatched** — System texts contractor with job details
3. **Contractor Confirms** — Reply CONFIRM when on-site, DONE when complete
4. **Family Confirms** — System texts family: "Did you receive your service? Reply YES"
5. **Both Sides Verified** — Status moves to "Verified Complete"
6. **Billing Auto-Created** — VERTEX generates claim with 22.5% DDI admin fee
7. **Supervisor Releases Payment** — No payment without verified status

If contractor says DONE but family says NO — escalation, investigation, no payment.

### System Access Points
- **Caseworkers** submit referrals at `/refer`
- **Navigators** manage families, track verification progress at `/navigator`
- **MDHHS** monitors SLA compliance, outcomes, and county data at `/mdhhs`
- **Families** track their case and confirm services at `/status`
- **Supervisors** approve services, release payments, monitor compliance
- **Contractors** confirm service delivery via SMS (no login required)

Every touch is logged. Every SLA is tracked. Every service is verified. Every payment is earned.
