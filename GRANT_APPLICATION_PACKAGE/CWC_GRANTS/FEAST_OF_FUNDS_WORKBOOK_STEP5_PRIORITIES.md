## QUESTION 1 — What is your #1 priority to strengthen before approaching funders?

### COPYABLE

```
Proof that our program systems actually run in production — not another pitch deck or new software module.

We already built NEXUS, SHIELD, PRISM, VERTEX, and HAVEN. The gap is documented evidence funders and MCOs can verify in one sitting:

• HAP CareSource NEMT — live portal, trip volume, SLA metrics, Vendor ID 100000469269 (Wayne + Macomb) compiled into a one-page “proof pack”
• SHIELD — working portal/demo + MDHHS-aligned KPIs (48-hour contact, testing within 14 days, verified service completion) — not slides only
• HAVEN — partner registry started + draft MCO disaster-continuity contract language tied to the same live NEMT infrastructure
• VERTEX — SHIELD and NEMT billing flowing so grants and contracts are auditable

We lead outreach with systems + live Michigan operations. We do not lead with “we’re building something.” Strengthen proof first; then MHEF, CFSEM, and health-plan meetings.
```

### SHORT

```
#1 priority: publish proof the systems run (HAP NEMT live metrics + SHIELD demo + HAVEN registry/clause draft + VERTEX billing) — not build more modules before funder meetings.
```

## QUESTION 4 — What is the biggest obstacle standing in your way right now?

### COPYABLE

```
Founder bandwidth — we are operating live NEMT, building SHIELD and HAVEN proof, and running grant outreach at the same time. Funders want evidence and meetings; operations want daily dispatch and billing. Both cannot be “later.”

Second: capital timing — navigator hires and marketing scale need grant dollars or contract expansion before we can hit public SHIELD KPIs at county scale.

Third: dependency on external gates — CWC SAM.gov validation (unlocks federal grants), MHEF Capacity Building RFP window (early April 2026), and health-plan meeting access for HAVEN rider language. We control the proof pack; we do not control their calendars.

Not the obstacle: lack of vision or systems — the systems exist. The obstacle is proving and staffing them fast enough that funders see a running machine, not a promise.
```

### SHORT

```
Biggest obstacle: founder time split between live ops and funder proof; need grant capital for navigators before county-scale SHIELD; waiting on SAM + MHEF RFP + MCO meeting access.
```
