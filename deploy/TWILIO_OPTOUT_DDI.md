# Twilio Advanced Opt-Out — DDI copy (console only)

Twilio does **not** expose Advanced Opt-Out message text via API. Update in Console:

**Messaging → Services → My New Notifications Service → Opt-Out Management → Advanced Opt-Out**

Use **DDI** (not Dee Davis Inc.) in member-facing lines. Legal name optional in HELP only.

---

## STOP (Opt-Out confirmation)

```
You are unsubscribed from DDI messages. No more texts will be sent. Reply START to resubscribe. Questions? Call 855-773-0035.
```

## START (Opt-In confirmation)

```
You are resubscribed to DDI appointment and ride updates. Reply STOP to unsubscribe. Member care: 855-773-0035.
```

## HELP

```
DDI member care — appointment & NEMT ride notifications. Reply STOP to unsubscribe, START to resubscribe. Call 855-773-0035 or email info@deedavis.biz. Legal entity: Dee Davis Inc.
```
