## 📧 SOURCES SOUGHT RESPONSE WORKFLOW:

### **STEP 1: Find Opportunity (5 min)**
- Go to SAM.gov
- Search: WOSB + Sources Sought + Active
- Find good opportunity

### **STEP 2: Add to NEXUS (2 min)**
- Open Airtable → OFFICER OUTREACH TRACKING
- Add new record:
  - Opportunity Title
  - Solicitation Number
  - Agency
  - Status: DRAFT
  - Priority: HIGH
  - Tags: WOSB, Sources Sought

### **STEP 3: Generate Capability Statement (5-10 min)**
**Use NEXUS Frontend (METHOD 1):**
- Open http://localhost:3000
- Document Generator → Capability Statements
- Fill in form based on opportunity
- Generate PDF

**OR Use Template (METHOD 2):**
- Open `DEE_DAVIS_CAPABILITY_STATEMENT.md`
- Customize for this opportunity
- Save as PDF

### **STEP 4: Write Response Email (10 min)**
Use template from `SOURCES_SOUGHT_RESPONSE_SYSTEM.md`:

```
Subject: Sources Sought Response - [Solicitation Number] - EDWOSB Vendor

Dear [Contracting Officer Name],

Dee Davis Inc. respectfully submits this capability statement in response 
to your sources sought notice for [Product/Service Name].

[Full template in the file]

Attachments:
- Capability Statement PDF
- W-9 Form
```

### **STEP 5: Submit & Track (5 min)**
- Send email
- Update NEXUS:
  - STATUS → SENT
  - DATE SENT → Today
  - FOLLOW-UP DATE → 7-14 days from now

**TOTAL TIME: 25-30 minutes per sources sought response**
