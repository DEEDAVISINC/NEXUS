## SERVICE LINE 2: NOTARY PERMIT RUNNER (NPR)

**Status:** 🟡 Due diligence complete — building target list next

### What It Is
A Notary Permit Runner submits construction permit applications, plans, and related paperwork to building departments on behalf of contractors/builders, then picks up and delivers the approved permits. Many permit forms require notarization — creating built-in synergy with existing notary services.

### How the Work Actually Goes (Step by Step)

1. **Client contacts DDI/3D Ink** — Contractor/builder says "I need a permit pulled for [address]"
2. **Intake** — Get project address, scope of work, contractor license info, permit type (building, electrical, plumbing, HVAC, roofing, sign)
3. **Research jurisdiction** — Which building department handles this address? In Michigan, LARA maintains a Statewide Jurisdiction List. Some cities have online portals, others are walk-in only
4. **Get the right form** — Every municipality has its own application. Download it, fill in basics (scope, address, contractor info), leave signature areas blank, send to client for approval/signature
5. **Assemble package** — Application + site plan + construction drawings + contractor license info + required docs. Some jurisdictions want 2 copies
6. **Submit** — Online (Accela, BSAonline, ePLANS) or in person at building department counter. Pay permit fee (client prepays or reimburses)
7. **Follow up** — Check review status. If corrections needed, communicate back to client, get revised docs, resubmit
8. **Pick up / deliver** — Once approved, pick up permit (or download), deliver to client or scan/email
9. **Invoice** — Bill per the contract terms. Get paid.

### Michigan Building Departments — Key Jurisdictions

| Municipality | Submission Method | Portal/Process |
|---|---|---|
| **Detroit** | Online only | Accela/eLAPS + ePLANS (ProjectDox) |
| **Troy** | Online (some via BSAonline.com, others via email) | BSAonline.com / building@troymi.gov |
| **Oakland County** | Online (environmental health via Accela) | aca-prod.accela.com/oaklandco |
| **State-level (LARA)** | Online | aca-prod.accela.com/lara |
| **Smaller townships** | Often walk-in counter only | Check LARA Statewide Jurisdiction List |

**Michigan Rule:** Contractors pulling permits must be licensed as a Residential Builder with LARA. The runner submits ON BEHALF of the licensed contractor — not in their own name.

### Why Notaries Are Specifically Sought for Permit Running

- Many permit application forms require notarization (affidavits, owner authorization, contractor statements)
- Signing services already route permit running assignments specifically to notaries
- Notaries have verified identity, background clearance, and professional conduct
- One trip = notarize documents AND submit permit application = two fees
- Authorization letters (some building departments require these) often need notarization

## SERVICE LINE 3: TWIC ESCORT SERVICES

**Status:** 🔴 Due diligence scheduled for May 23, 2026

### What It Is
TWIC (Transportation Worker Identification Credential) is a TSA/DHS program. TWIC cardholders can access secure maritime/port facilities. Non-TWIC visitors, vendors, and workers must be escorted by someone with a TWIC card. DDI/3D Ink provides the escort service.

### The TPA Model
- DDI holds contracts with ports, refineries, chemical plants, LNG terminals, maritime facilities
- DDI dispatches credentialed 1099 TWIC escorts
- DDI keeps the spread between client rate and escort pay
- **NATIONWIDE** — not just Michigan. Everywhere there's a port or TWIC-required facility

### Service Type Routing in PRISM

```
Assignment comes in → PRISM identifies service type:
  - "notary_signing" → dispatch notary agent
  - "permit_run" → dispatch NPR-certified agent
  - "twic_escort" → dispatch TWIC-credentialed agent
  - "fingerprinting" → dispatch fingerprint tech
  - "drug_test_collection" → dispatch collector
  
All use the same dispatch engine, same agent pool (agents can be multi-credentialed),
same billing flow, same quality tracking.
```
