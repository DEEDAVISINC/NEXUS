## 🔧 TROUBLESHOOTING GUIDE

### **API won't start?**
```bash
# Check Python packages
python3 -c "import reportlab, PyPDF2, flask, pyairtable"

# Install if missing
pip install reportlab PyPDF2 flask flask-cors pyairtable
```

### **PDF not generated?**
```bash
# Create directory
mkdir -p generated_rfps
chmod 755 generated_rfps

# Check API logs for errors
```

### **Watermark missing?**
```bash
# Upgrade PyPDF2
pip install --upgrade PyPDF2

# Note: RFP still works without watermark
```

### **Airtable errors?**
```bash
# Check .env file
cat .env | grep AIRTABLE

# RFP generation works WITHOUT Airtable
# (just won't save to database)
```
