# DDI Foreign Entity Registration — All 50 States + DC (Verified)

**Entity:** Dee Davis Inc. (Michigan domestic **corporation**)  
**Last updated:** June 2, 2026 — **All 50 states + DC SOS-verified** (foreign corp qualification fees)  
**Purpose:** Foreign **corporation** qualification fees (Certificate / Application for Authority).  
**Home state:** Michigan — attach **MI Certificate of Good Standing** (~$10 from LARA) unless a state says otherwise.

**DDI policy — upon award only:** Do **not** foreign-qualify because an opportunity exists in a state. File **only after contract award** when performance, invoicing, or enrollment requires it — or when an RFP **pass/fail requires** qual at proposal submission. See `.cursor/rules/foreign-entity-upon-award-only.mdc`. This file is a **fee lookup after a win**, not a pre-bid checklist.

## Filing process (standard — all states)

```
1. Confirm you are "doing business" in the state (or bid/Medicaid contract requires qualification)
2. Order MI Certificate of Good Standing from LARA (~$10)
3. Confirm legal name available in target state (name search on SOS portal)
4. Some states require name reservation FIRST (Alabama — $25–28)
5. Appoint registered agent with in-state street address (family or commercial)
6. File Application for Authority / Certificate of Authority + good standing
7. Pay SOS filing fee (see table)
8. Complete any same-day mandatory add-ons (NV Initial List + Business License, FL RA fee online)
9. Register for state taxes / annual reports as required
10. File assumed name ONLY if invoicing under a trade name other than Dee Davis Inc.
```
