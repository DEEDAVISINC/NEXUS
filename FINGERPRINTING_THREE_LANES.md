## THE THREE LANES

### LANE 1: INTERSTATE PROFESSIONAL LICENSURE
**What:** Professionals who need licensure in a state other than their home state must get FBI-level fingerprints on FD-258 cards
**Who Needs It:**
- Real estate agents (every state transfer)
- Insurance agents/adjusters (multi-state licensing)
- Nurses / RNs / LPNs (compact states still require background checks)
- Physicians / dentists (every state board)
- Attorneys (bar admission in new states)
- CPAs / accountants (state board licensing)
- Pharmacists (state board)
- Mortgage brokers / loan originators (NMLS, state DFS)
- Private investigators / security professionals
- Child care workers (interstate transfers)
- Liquor license applicants

**The Buyers:**
- State licensing boards (real estate commission, board of medicine, board of nursing, dept of insurance, dept of financial services)
- The professionals themselves (B2C walk-in / mobile service)
- Staffing agencies placing licensed professionals across state lines
- Healthcare systems onboarding traveling nurses / locum tenens
- Real estate brokerages expanding to new states

**DDI's Edge:**
- Most local LiveScan shops only do state-level prints
- DDI does FD-258 (FBI standard) — the format required for interstate licensure
- Some states have their own cards (Ohio, Maryland) — DDI can accommodate all formats
- Mobile service = DDI goes to the brokerage, hospital, or agency location

**Volume:** Millions of licensed professionals move states every year. Every single one needs fingerprints.

**Pricing:** $50/card, $150 new client (2-card minimum + mobile). Add $50 for SWFT/FBI submission + results = $200 bundled per new client.

### LANE 2: ATF / NFA FIREARMS
**What:** ATF requires FD-258 fingerprint cards and/or EFT (Electronic Fingerprint Transmission) files for:
- NFA Form 4 transfers (suppressors, SBRs, SBSs, machine guns, AOWs, destructive devices)
- NFA Form 1 (making an NFA item)
- FFL applications and renewals (Federal Firearms License)
- Responsible Person submissions (every owner, partner, board member of an FFL entity)
- Explosives license/permit applications
- **Gun registration** — all NFA items require fingerprint submission for registration in the National Firearms Registration and Transfer Record (NFRTR)

**Who Needs It:**
- Individual NFA applicants (buying a suppressor, SBR, etc.)
- Gun trusts — EVERY responsible person on the trust needs separate prints
- Corporate/LLC applicants — every officer, director, possessor
- FFL dealers (new applications + renewals)
- FFL responsible persons (SOT, manufacturer, dealer, importer)
- Explosives licensees

**The Buyers:**
- FFL dealers / gun stores (who refer their customers for prints)
- NFA dealers (Class III dealers) — high volume, every sale triggers prints
- Gun trust attorneys / services (National Gun Trusts, SilencerShop, Capitol Armory)
- Shooting ranges that sell NFA items
- The applicants themselves (B2C)

**DDI's Edge:**
- EFT file creation (ANSI/NIST-ITL compliant, 500+ DPI, WSQ compression) — most police departments and UPS stores can't do this
- FD-258 to EFT conversion service
- One EFT file is reusable for all future NFA applications — DDI creates it once, customer uses it forever
- Mobile fingerprinting at gun stores, ranges, and FFL locations
- Current providers: UPS Stores ($55), National Gun Trusts ($55), PrintScan ($75-86), SlapEFT (software only). DDI can compete on price and convenience.

**Volume:** 
- 130,000+ FFLs in the US, each with multiple responsible persons
- NFA applications are surging (suppressor market alone)
- Every Form 4 = 2 FD-258 cards per person (paper) or 1 EFT file (electronic)
- Electronic eForms process 3-4x faster than paper — driving demand for EFT

**Pricing:** $50/card, $150 new client (2-card minimum + mobile). EFT file creation via Lakota ($85/mo flat). Add $50 for SWFT/FBI submission + results = $200 bundled.

### LANE 3: FEDERAL CONTRACTS — DDI + LAKOTA NATIONWIDE PLATFORM
**What:** Federal agencies (DHA, DeCA, SSA, DoD branches) require nationwide fingerprinting services with SWFT submission to DCSA. DDI primes these contracts. Lakota provides SWFT technology. Independent operators provide collection sites.

**The Platform Model:**
- DDI = Prime contractor / TPA (contract management, compliance, reporting, QA, network management)
- Lakota = Technology partner (SWFT submission, WHORL livescan software, portal/scheduling)
- Independent livescan operators = Collection network (physical sites in all 50 states + territories)
- This is the ONLY open-network alternative to Fieldprint in the federal fingerprinting market

**Who Needs It:**
- Defense Health Agency (DHA) — background investigations for military/civilian/contractor employees
- Defense Commissary Agency (DeCA) — all DeCA position background checks
- Social Security Administration (SSA) — employee background investigations (~22,000/year)
- DoD branches — security clearances, contractor onboarding, suitability determinations
- Any federal agency requiring nationwide SWFT fingerprinting

**The Buyers:**
- Federal agency security divisions and HR departments
- Military base security offices
- Defense contractor HR departments
- DCSA (for SWFT-enrolled fingerprinting programs)

**DDI's Edge:**
- EDWOSB/WOSB — set-aside eligible (DHA HT001126QE014 is WOSB set-aside)
- Lakota built FBI NGI, DoD ABIS, DHS HART — unmatched technology credibility
- TPA model proven across drug testing (PRISM) and NEMT (Uber Health)
- Open network model = scalable without building/owning physical sites
- Only competitor to Fieldprint's closed 2,200-site network
